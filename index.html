dotnetassertions
github.com/JohnVerheij

AOT-safe assertions for TUnit.

Nine small packages. Each adds a fluent Assert.That(...) vocabulary for one domain: logs, time, snapshots, math, JSON, SSE, gRPC, traces, and metrics. Reflection-free, MIT, test projects only.

await Assert.That(collector).HasLogged().AtLevel(LogLevel.Warning).Once();
await Assert.That(time).HasNoActiveTimers();
await Assert.That(json).HasJsonValue("user.age", 30);

Not a general-purpose assertion library. TUnit's own assertions stay as they are; these packages only add domain vocabulary on top of them.

The packages target every .NET version in Microsoft support: .NET 10 and .NET 11 today.

The family

LogAssertions.TUnit

Filter captured ILogger records by level, message, exception, property and scope, then assert counts, order, or that nothing above a level was logged. Failures print the captured records.

await Assert.That(collector).HasLoggedOnly(LogLevel.Warning);
dotnet add package LogAssertions.TUnit
DocsNuGetGitHub

TimeAssertions.TUnit

Assert fake-clock state, timer leaks, fire counts and due times, and put a time budget on any assertion with WithinTimeBudget.

await Assert.That(fakeTime).HasAdvancedExactly(TimeSpan.FromMinutes(31));
dotnet add package TimeAssertions.TUnit
DocsNuGetGitHub

SnapshotAssertions.TUnit

Text snapshots with plain .expected.txt baselines and line diffs. Scrubbers replace GUIDs, timestamps and epoch values with stable tokens.

await Assert.That(actual).MatchesSnapshot().WithScrubber(Scrubbers.Default);
dotnet add package SnapshotAssertions.TUnit
DocsNuGetGitHub

MathAssertions.TUnit

Tolerance-aware checks for vectors, quaternions, matrices and poses, including rotational equivalence. Also statistics, sequences, number theory and 3D geometry.

await Assert.That(rotation).IsRotationallyEquivalentTo(expected, tolerance: 1e-6);
dotnet add package MathAssertions.TUnit
DocsNuGetGitHub

JsonAssertions.TUnit

Assert at a path such as items[*].name: existence, value, array length, subset and equivalence. Works on strings, JsonElement and HTTP responses, with ProblemDetails checks.

await Assert.That(json).HasJsonProperty("items[*].name");
dotnet add package JsonAssertions.TUnit
DocsNuGetGitHub

SseAssertions.TUnit

Assert named events, data, ids and retry directives on an SSE body, Stream or HTTP response. Reads stop once the outcome is decided, so endless streams work.

await Assert.That(body).HasSseEvent("tick").Exactly(3);
dotnet add package SseAssertions.TUnit
DocsNuGetGitHub

GrpcAssertions.TUnit

Assert that a call throws an RpcException with a given status, detail or trailer, and check server streams. GrpcCallBuilder builds fake calls.

await Assert.That(async () => await client.GetOrderAsync(request, cancellationToken: ct))
    .ThrowsGrpcException(StatusCode.Unavailable);
dotnet add package GrpcAssertions.TUnit
DocsNuGetGitHub

TracingAssertions.TUnit

Capture spans per test, then find spans and assert tags, kind, status, parent and child links, and durations. A renderer prints the captured spans as a tree.

await Assert.That(capture).HasSpanWithTag("order.place", "order.id", 42);
dotnet add package TracingAssertions.TUnit
DocsNuGetGitHub

MetricsAssertions.TUnit

Capture System.Diagnostics.Metrics instruments per test and assert counter totals, measurement counts, tags and histogram samples. One capture can bundle several instruments.

await Assert.That(capture).HasCounterTotal(5);
dotnet add package MetricsAssertions.TUnit
